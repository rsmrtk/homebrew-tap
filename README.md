# homebrew-tap

Homebrew tap for [helmsman](https://github.com/rsmrtk/helmsman), a terminal UI for Kubernetes.

```sh
brew install rsmrtk/tap/helmsman
brew upgrade helmsman
```

`Formula/helmsman.rb` is generated by `scripts/update_formula.py` from the latest GitHub release (its
`checksums.sha256`). The `update-formula` workflow runs every three hours and on demand, and commits when a new
release has appeared.
